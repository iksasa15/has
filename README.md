# بوصلة UT — قالب الكتيب

قالب Microsoft Word قابل للطباعة لمذكرة المستجد **بوصلة UT** بهوية كتيب أرشدني.

## الملفات

| ملف | الوصف |
|-----|--------|
| `بوصلة-UT-قالب.docx` | القالب الجاهز للفتح والتعديل والطباعة |
| `build_booklet.py` | سكربت إعادة توليد القالب |
| `fonts/` | خطوط thmanyah sans (OTF) |
| `_assets/` | شعار جامعة تبوك + أيقونات |
| `pages/` | صفحات الكتيب كصور PNG (A5 @ 300dpi) |
| `بوصلة-UT-كتيب.pdf` | كل الصفحات في ملف PDF واحد |
| `build_images.py` | سكربت توليد الصفحات كصور |

## قالب الصور (موصى به للتصميم)

```bash
python3 build_images.py
```

ينتج ملفات في `pages/` + `بوصلة-UT-كتيب.pdf` بخط thmanyah sans وشعار جامعة تبوك الرسمي.

## تثبيت الخطوط (مهم قبل الطباعة — لقالب وورد)

Word يستخدم أسماء العائلات كما هي داخل ملفات `fonts/`:

- `thmanyah sans` — Regular / Bold
- `thmanyah sans Med` — Medium
- `thmanyah sans Light` — Light
- `thmanyah sans Black` — Black

ثبّت الملفات على جهازك:

1. افتح مجلد `fonts/`
2. انقر مرتين على كل ملف `.otf`
3. اضغط **Install Font**
4. أعد فتح Word ثم افتح `بوصلة-UT-قالب.docx`

بدون التثبيت سيظهر خط بديل وقد يختلف شكل الصفحات.

## مقاس الطباعة

- **A5 عمودي** (14.8 × 21 سم)
- مناسب للطباعة ككتيب (صفحتان A5 على ورقة A4 عند الطي)

## الصفحات داخل القالب

1. **غلاف** — بوصلة UT / مذكرة مستجد
2. **صفحة الاسم** — خلفية بنفسجية مع سطور الاسم والتوقيع والتاريخ
3. **٥ نصائح** — عمودان + صندوق اقتباس
4. **محتوى القسم** — خلفية كريمية + لوحة ألوان + فوتر أرشدني
5. **ملاحظاتي** — أسطر كتابة + فوتر أرشدني
